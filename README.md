# Cybersecurity Log Analyzer

## Overview
A Python-based security tool that analyzes web server logs
and detects suspicious activities.

## Features
- SQL injection detection
- XSS detection
- Brute-force detection
- Security report generation

## Technologies
- Python
- Linux

## How It Works
1. Reads web server logs
2. Identifies suspicious requests
3. Categorizes attacks
4. Generates a security report
